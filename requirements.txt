# Pinned environment for the cross-family DTI study.
#
# Why these are pinned: RDKit's canonical atom ranking and canonical SMILES
# output can differ between releases, and the tautomer canonicalisation code
# has changed. This project uses canonical SMILES as the basis of
# deduplication and of the R4b chemical split, so a different RDKit version
# yields different splits and therefore different results. Data-source
# versions (ChEMBL, UniProt) and model checkpoint revisions are pinned in
# docs/versions.md.
#
# Python 3.12.10. Install with:
#
#   py -3.12 -m venv .venv
#   .venv/Scripts/activate            # Windows
#   pip install -r requirements.txt
#
# MMseqs2 is NO LONGER REQUIRED. The R3 split needs pairwise identity between
# 565 target domains, which is 159,330 pairs -- small enough to align exactly
# (biopython, below) in under a minute across the machine. MMseqs2's k-mer
# prefilter saves nothing at that size and is a heuristic whose recall matters
# precisely at the 0.40 identity cutoff, where a missed pair would leave a test
# target similar to a training one. See K22 in docs/decisions.md.
#
# Hardware this was pinned for: single NVIDIA RTX 4050 Laptop, 6 GB VRAM.
# That budget allows frozen ESM-2 650M inference in fp16 and partial
# fine-tuning of ChemBERTa-2; it does not allow ESM-2 3B.
